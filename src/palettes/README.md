# Palettes

Colors come from [Ayu](https://github.com/ayu-theme/vscode-ayu) (`ayu` colors v7, as shipped around mid-2020): Ayu Dark for `pustota`, Ayu Light for `pustota light`, where each color plays the same role as its dark counterpart.

`name`, `type` and `filename` describe the VSCode theme, `colors` are grouped by role: `base`, `accent`, `syntax`, `selection`, `vcs`, `terminal`.

`syntax.constant`, `syntax.operator` and `syntax.error` are only used in UI, not in code.

To add a palette, create a JSON file here and list it in `build.js` and `package.json`.
