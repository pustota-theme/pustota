# Changelog

All notable changes to the "pustota" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## 0.35.0

- In Python fixed that some regex patterns where highlighted as keywords
- In TypeScript fixed `null` and `undefined` highlight in type annitations
- In TypeScript fixed `accessor` to be a keyword
- In TypeScript fixed `namespace` to be a keyword
- In TypeScript fixed `10n` to be a constant
- In JavaScript and TypeScript some properties like `Math.PI`
  are no longer highlighted as a constant
- In Ruby fixed `4r`, `3i` and `1.5ri` to be constants
- In Ruby fixed `@@` to be highlighted the same way as `@`
- In Ruby fixed module name highlight
- In Go fixed `0b` and `0x` highlight as numbers, not keywords

## 0.34.0

- Added `typedef` name highlight in C via semantic tokens
- Added `struct` and `interface` definition name highlight
  in Go via semantic tokens, other type definitions
  like `type Set []interface{}` are not highlighted
- Removed type alias name highlight in TypeScript,
  `type Matcher = {...}` is not highlighted
- In TypeScript `type Alias = String` is no longer highlighted as a class
- In TypeScript fixed highlight `prop: () => number = () => {}` as method
- In TypeScript fixed `class Test2 extends Module.Class {}` highlight,
  now `Module` is not highlighted
- In Ruby fixed `require` highlight, it is now a keyword
- In Ruby fixed `new` and `private` highlight, they are now keywords

## 0.33.0

- Added semantic highlight support
- Added `pustota contrast` theme, a brighter variant of `pustota`
- Fixed `type` keyword highlight in Python
- Fixed method highlight when method name matches builtin type name in Python

## 0.32.0

- Added `pustota light` theme, based on Ayu Light colors
- Theme files are now generated by `npm run build`
  from a shared layout (`src/theme.js`) and per-theme palettes (`src/palettes/`)

## 0.31.0

- Fixed `#[]` highlight in Rust, now only `#` is highlighted
